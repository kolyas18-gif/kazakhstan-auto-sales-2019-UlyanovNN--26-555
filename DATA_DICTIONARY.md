# Словарь итогового датасета

| Поле | Значение | Пропуски |
|---|---|---|
| company | Нормализованное название компании источника | Нет |
| brand | Бренд | Нет |
| model | Модель | Нет |
| manufacture_year | Год выпуска, Int64 | Допустимы, не восстановлены без оснований |
| country | Страна производства, ALPHA-3 | Нет |
| fuel_type | F бензин, D дизель, E электропривод, HYB гибрид; category | Допустимы |
| engine_l | Объём ДВС, литры; 0 для электромобиля | Допустимы; не подменены нулём |
| transmission | Автомат / Механика; category | Допустимы |
| drive_type | 4WD / FWD / RWD / 2WD; category | Допустимы; у 2WD ось неизвестна |
| region | Регион/город продажи, включая Экспорт | Нет |
| unit_price_usd | Цена одного автомобиля, USD | Нет |
| area | Область/город республиканского значения по источнику | Нет |
| segment_2013 | Сегментация 2013; category | Нет |
| class_2013 | Класс 2013; category | Нет |
| sale_date | Последний календарный день месяца продажи; datetime | Нет |
| is_return | True, если количество отрицательное | Нет |
| is_export | True, если регион Экспорт | Нет |
| quantity | Суммарное число автомобилей в группе; Int64; возвраты отрицательные | Нет |
| total_sales_usd | Сумма продаж группы в USD, с учётом возвратов | Нет |
| source_records | Число очищенных записей до финальной агрегации | Нет |

Количество и сумма аддитивны; цены, доли и средние — нет. Для средней стоимости автомобиля используйте сумму положительных total_sales_usd / сумму положительных quantity. Не усредняйте unit_price_usd без веса quantity. Для общего объёма используйте сумму quantity, не число строк и не сумму source_records.

Количество строк с пропусками и фактические типы приведены в `data/schema.csv`. Пропуск в CSV — пустое поле. Категории и datetime восстанавливаются `read_clean()`.

# Продажи автомобилей в Казахстане — 2019

Курсовой проект: анализ рынка и позиций «Меркур Авто».

- `01_initial_review.ipynb` — первичная проверка данных.
- `02_cleaning.ipynb` — очистка и создание итогового CSV.
- `03_market_eda.ipynb` — анализ рынка.
- `04_mercur_analysis.ipynb` — анализ «Меркур Авто».
- `clean_data.py`, `analysis_utils.py` — функции обработки и анализа.
- `data/autokz2019_raw.csv` — исходные данные.
- `requirements.txt` — зависимости Python.

Тетради содержат сохранённые результаты. Для повторного расчёта установите зависимости из `requirements.txt` и выполните тетради в порядке 01–04. Очищенный CSV, таблицы и графики создаются автоматически.

# Продажи автомобилей в Казахстане — 2019

Курсовой проект: анализ рынка за январь–сентябрь 2019 года и позиций «Меркур Авто».

Содержимое репозитория:

- `01_initial_review.ipynb` — первичная проверка данных.
- `02_cleaning.ipynb` — очистка данных.
- `03_market_eda.ipynb` — анализ рынка.
- `04_mercur_analysis.ipynb` — показатели «Меркур Авто».
- `clean_data.py`, `analysis_utils.py` — функции обработки и анализа.
- `requirements.txt` — зависимости Python.
- `data/` — исходные, очищенные и промежуточные данные; итоговый файл — `autokz2019_clean.csv`.
- `tables/`, `figures/` — результаты расчётов и графики.
- `notebook_html/` — HTML-копии тетрадей.
- `DATA_DICTIONARY.md` — описание полей датасета.
- `REQUIREMENTS_CHECKLIST.md`, `verify_project.py`, `verification_result.json` — материалы проверки проекта.
- `build_notebooks.py`, `enrich_notebooks.py`, `execute_notebooks.py`, `build_report.py` — вспомогательные скрипты подготовки материалов.

Тетради сохранены с результатами; порядок выполнения — 01–04.
